# RESTful_Web_API.NET_Core
RESTful web API (C#) .NET 10 API with Authentication

About the Project
This project is part of my learning journey into building secure, scalable, and maintainable RESTful Web APIs using ASP.NET Core (NET 10).
Focusing on developing an API from the ground up, implementing authentication and authorization, working with databases, and following best practices for modern .NET API development.

Objectives

•	Understand RESTful API principles and HTTP methods.
•	Build RESTful endpoints using ASP.NET Core Web API.
•	Implement CRUD (Create, Read, Update, Delete) operations.
•	Work with Entity Framework Core and database migrations.
•	Implement authentication and authorization.
•	Secure API endpoints and manage user access.
•	Handle validation, errors, and HTTP responses correctly.
•	Test API endpoints using tools such as Scalar UI.
•	Apply clean coding practices and maintainable project architecture.

Technologies

•	Framework: ASP.NET Core .NET 10
•	Language: C#
•	API Architecture: REST
•	ORM: Entity Framework Core
•	Database: SQL Server
•	Authentication: To be implemented during the course
•	API Documentation: Scalar
•	Development Environment: Visual Studio
